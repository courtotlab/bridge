# Bridge

FastAPI + React app wrapping [llm-ontology-mapper](https://github.com/akandwal/llm-ontology-mapper) for clinical researcher ontology mapping workflows.

## Planned Stack

- **Backend**: FastAPI (Python 3.10+)
- **Frontend**: React with TypeScript
- **Python dependency management**: uv with pyproject.toml
- **Docker**: planned for later

## Current Status

Initial scaffold — folder structure only, no features implemented yet.
